## 业务说明

承接飞书审批的付款申请信息，生成付款单；提交复核通过后，通过万里汇付款接口出款；付款完成后获取万里汇回单，并上传至飞书审批流。

## 菜单（左侧）

1. **初审付款单** `/submit`（仅待初审；支持初审、批量初审、已线下付款、作废。未勾选时点击批量初审提示「请先勾选数据！」。点击已线下付款并确认后，状态改为已完成）
2. **复核付款单** `/review`（仅待复核；明细只读；付款渠道只读不可编辑，未写入时展示万里汇，确认时系统写入；支持复核确认/退回。未勾选时点击批量复核提示「请先勾选数据！」。已勾选时弹窗提示「请选择付款渠道和提出币种」，付款渠道默认万里汇，提出币种可选 USD（美元）、CNY（人民币）、HKD（港币））
3. **查询付款单** `/query`（全部状态，含已作废。作废、重新支付仅在付款单为待支付且支付状态为支付失败时显示。作废确认后状态改为已作废。重新支付再次发起支付，成功后提示「已成功提交支付，请稍等。」，状态改为待回单、支付成功）
4. **查询比对结果** `/compare`（付款单与审批单对照：编号、金额、审批币种、收款人、收款账号；比对结果为一致/不一致；不含已作废付款单）

复核退回后状态变为待初审，单据回到「初审付款单」列表。

## 查询条件

付款单号、审批单号、付款申请类型、审批金额、付款事由、收款方式类型  


按钮：【搜索】【重置】

## 列表字段

付款单号、审批单号、审批单名称、付款申请类型、付款事由、审批金额、审批币种、收款金额、收款币种、收款人/户名、收款账户、收款银行、收款方式类型、申请人ID、申请人名称、申请时间、付款单状态、创建时间、更新时间

审批币种：美元、人民币、港币。收款金额 = 审批金额，收款币种 = 审批币种。初审、复核列表不展示提出金额、提出币种。查询列表在收款币种后展示这两列，提出金额 = 收款金额/汇率+手续费，提出币种在复核明细中选择。

查询引导页在付款单状态右侧另有：支付状态、支付失败原因。

## 明细字段

付款单号、审批单号、审批单名称、付款申请类型、付款单状态、付款渠道、付款事由、转账附言、审批金额、审批币种、收款金额、收款币种、手续费、提出金额、提出币种、收款方式类型、申请人ID、申请人名称、申请时间。明细不展示费用具体明细。

收款账户信息另有：账户类型、收款人/户名、收款账号、收款银行、银行所在地区、银行支行、联行号、清算系统（SWIFT/BIC）、收款银行（境内/境外）、收款人身份证号码、收款人邮箱号码、收款人手机号码。每行 3 个字段。手续费与提出金额同币种，提出金额 = 收款金额/汇率+手续费。

付款渠道在初审、复核明细位于付款单状态右侧，只读。复核未写入时为万里汇下拉框且不可改。提出币种仅在复核编辑态可下拉选择 USD（美元）、CNY（人民币）、HKD（港币），提出金额按万里汇汇率重算。初审/复核可填写本次处理意见。明细页底部「处理历史」面板展示已办环节与处理意见。查询明细在付款单状态右侧展示支付状态，并在处理历史前展示回单信息（付款流水号、回单时间、付款回单附件，下一行是占满整行的支付失败原因）。

## 状态流转

待初审 →（初审）→ 待复核 →（复核确认）→ 待支付 →（万里汇付款成功）→ 待回单 →（获取回单并回传飞书）→ 已完成  
待初审 →（已线下付款）→ 已完成  
待复核 →（退回）→ 待初审  
待初审 →（作废）→ 已作废（逻辑删除：只改状态，不删除单据；初审列表不再展示，查询可查看）
