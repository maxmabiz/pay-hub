# 导入为飞书云文档

当前环境没有飞书开放平台凭证，无法直接在 `bestfulfill.feishu.cn` 创建云文档。请用下面任一方式导入，导入后即为飞书云文档，可评论、@人、会签。

## 方式一：导入 Word（推荐）

1. 打开飞书，进入目标知识库或「云文档」。
2. 点击「新建」旁的「…」或把文件拖进知识库。
3. 选择导入，上传 `docs/付款中心需求说明书.docx`（与 `docs/feishu/付款中心需求说明书.docx` 内容相同）。
4. 导入完成后改名为「付款中心需求说明书」。

## 方式二：导入 Markdown

1. 飞书云文档支持导入 `.md`。
2. 上传仓库中的 `docs/付款中心需求说明书.md`。
3. 标题、表格、分级标题会转成云文档样式。

## 方式三：复制粘贴

将 Markdown 正文复制到空白飞书文档。表格需再检查列宽。
